NokNokware · SecureGuard Pro

Six-month device licensing

SecureGuard Pro is an offline records application for Windows desktop and Android. Licensing adds online activation while agency records and attachments remain local and independent on each device.

Activation service available: License activation takes place inside a configured SecureGuard Pro app using the NokNokware Licensing service on Appwrite Cloud. This page does not issue keys, activate installations, accept payments or offer an automated checkout.

One license, one installation

A license is assigned to one installation on one Windows PC user profile or one Android phone. A PC and phone need separate licenses. Copying the installer does not transfer an activated license. Activation takes place inside SecureGuard Pro, with an internet connection.

Six calendar months

The server grants a signed license term of six calendar months from activation, using UTC. If the corresponding day does not exist in the ending month, the term ends on that month's last day at the same UTC time. The app displays the exact expiry; this is not a fixed 180-day term.

An activated installation can work offline until its signed expiry, subject to successful local validation. Set the device clock correctly. Renewal requires an issued renewal key and an online request in the app; there is no automatic payment or renewal on this page. Activating a renewal starts a fresh six-month term immediately; unused time is not appended.

Records remain yours after expiry

When a license expires, paid editing is locked. Existing users can still authenticate, view records, export permitted reports and create backups under their account permissions. Licensing does not delete agency records or remove the need for secure backups.

Reinstalls and device transfers

Contact NokNokware before reinstalling, replacing a PC or phone, or clearing app storage. Device transfers require publisher assistance and are not automatic. Keep encrypted backups and their passphrases securely before changing devices. Never send passwords or backup passphrases to support.

Licensing and privacy

The activation service uses licensing identifiers and the installation's public cryptographic identity to check entitlement. The service stores the product, license status, installation public key, platform, activation and expiry times. Appwrite may also process network addresses and operational logs. Agency personnel records and attachments are not sent for activation. Do not put license keys in a web address or email, and do not send databases, backups or personnel documents for licensing support.
